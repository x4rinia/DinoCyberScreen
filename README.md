# DinoCyberScreen

![DinoCyberScreen Preview](docs/implementation-black-green-1920x1080.png)

**DinoCyberScreen** is a modern, sci-fi inspired Windows screensaver. It turns your idle screen into a futuristic heads-up display (HUD) that shows real-time system telemetry and a holographic Ankylosaurus.

## Features

- **Live Telemetry:** Displays your real-time CPU and GPU temperatures directly on your screen.
- **Cyberpunk Aesthetics:** A sleek, dark user interface with glowing accents.
- **Holographic Visuals:** Features a futuristic Ankylosaurus hologram as the centerpiece.
- **Multi-Monitor Support:** Works seamlessly across all your connected displays.

## Installation

Installing DinoCyberScreen is incredibly easy. Just follow these steps:

1. Download the latest release folder.
2. Open the elease folder.
3. Double-click the **Install-Screensaver.bat** file.
4. If Windows asks for Administrator permissions, click **Yes** (this is required to copy the screensaver to your Windows System32 folder).

The script will automatically install all necessary files and open your Windows Screensaver Settings. You will see "DinoCyberScreen" already selected in the dropdown menu.

## Uninstallation

If you ever want to remove it:
1. Open the elease folder again.
2. Double-click the **Uninstall-Screensaver.bat** file.
3. The screensaver will be cleanly and completely removed from your system.
